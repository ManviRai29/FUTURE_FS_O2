# Client Lead Management System

A simple full-stack CRM built to manage client leads in one place. The project includes an admin login, lead management, status tracking, and follow-up notes.

I built this project as part of my Future Interns Full Stack Web Development internship.

## What it does

The main idea is to make it easier to keep track of leads without having everything scattered across different places.

### Features

- Admin login
- Dashboard for viewing leads
- Add and manage client leads
- Update lead status
- Add follow-up notes
- View lead details
- MongoDB database for storing data
- Backend API for handling the application logic
- Responsive frontend

## Tech Stack

**Frontend**
- React
- JavaScript
- CSS

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB
